# 实验室安全课程学习辅助程序

使用 Python 和 Microsoft Edge 辅助学习实验室安全课程：手动登录学校平台后，程序读取课程进度，辅助文档阅读、视频播放和课程切换，并等待网站确认学习记录。

项目拥有独立的 Python 虚拟环境、浏览器配置、日志和进度文件。当前适配兰州交通大学实验室安全教育平台，默认课程为 **2026年实验室安全准入考试（研究生和教职工）**。

程序使用页面正常计时和正常倍速播放，完成状态以网站记录为准。学习辅助结束后，由使用者自行参加考试。

**第一次使用，按“下载源码 → 安装环境 → 核对配置 → 检查课程并登录 → 验证计时 → 开始学习”的顺序操作。** 下面每一步都给出操作方法和应看到的结果。

## 主要功能

- 读取“未学／已学”列表的全部分页，按课程身份去重；时长要求和课程数量从当前页面读取。
- 完成未达标必学，再按列表顺序处理选学；选学累计达到要求后停止。
- 文档按要求时长分配翻页，视频按 1 倍速播放，并监测暂停、缓冲、播放结束和计时停滞。
- 前一课程到学时核对时间时，延后核对到当前文档或视频满足本次学习计时后，避免提前退出。
- 材料刚打开时等待计时器数据加载，避免把临时显示的 00:00 要求误当成时长不一致；持续不一致仍保留页面并暂停。
- 对播放已结束但学习时长不足的视频，确认明确的重播提示并继续正常播放。
- 视频补学同时满足网页计时和实际播放时长；本平台按 15 秒上传学时，短时补学会覆盖完整上传周期后再返回。
- 题库按每 15 分钟最多提交 1 道已核验练习题后轮换，退出后核对网站实际累计学时。
- 保存待确认和网站已确认记录；中断重启后重新读取网站进度，核对本地状态。
- 支持课程检查、真实计时验证、完整学习，以及暂停、继续和停止控制。

## 一、使用前需要准备什么

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows；当前启动脚本与浏览器查找逻辑针对 Windows |
| Python | 建议使用 3.12，安装后终端中的 `python` 命令应可用；其他版本尚未逐一验证 |
| 浏览器 | 已安装 Microsoft Edge，使用有界面的专用窗口 |
| 学校账号 | 能手动登录平台，并有权限查看目标课程 |
| 网络 | 能访问学校平台；首次安装还需要下载 Python 依赖和 Edge 驱动 |
| 运行条件 | 保持学习窗口可见、网络稳定，避免电脑休眠 |

Python 依赖见 [requirements.txt](requirements.txt)，安装脚本会创建项目自己的 `.venv` 并安装依赖。项目不需要填写或保存登录密码，网页登录由使用者手动完成。

默认浏览器后端为 `native`，通过本机调试接口连接专用 Edge，使用 Selenium 的等待与异常处理。安装脚本同时准备匹配 Edge 的驱动，供可选的 `webdriver` 后端和本地浏览器测试使用。

### 第 1 步：安装 Python，确认命令可用

从 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/)获取 Python 3.12 系列的 Windows 安装包。安装器提供 **Add python.exe to PATH** 选项时，勾选后再安装。安装完成后重新打开 PowerShell，执行：

```powershell
python --version
```

应看到 `Python 3.12.x` 这样的输出。Microsoft Edge 也应能正常打开；需要安装时使用[微软官方下载页](https://www.microsoft.com/edge/download)。

使用 GitHub 网页下载 ZIP 并运行程序，不需要安装 Git。

## 二、下载、安装与配置

### 第 2 步：下载完整源码，进入项目目录

1. 打开本项目的 GitHub 仓库主页。
2. 点击绿色 **Code → Download ZIP**。
3. 将下载的 ZIP 解压到自己容易找到的目录。
4. 打开解压目录，找到同时包含 `main.py`、`settings.json`、`setup.cmd` 的文件夹。ZIP 可能多套一层目录，以实际文件位置为准。
5. 在文件资源管理器地址栏输入 `powershell` 并按回车，在当前目录打开终端。

执行以下命令，确认能看到上述文件：

```powershell
Get-ChildItem
```

**后续命令都在这个项目目录执行，代码块按行执行。** 项目不依赖固定磁盘路径。GitHub 的 **Code → Download ZIP** 会下载当前分支源码；本机 `dist/` 中的旧交付包可能早于当前代码，普通使用者从仓库获取源码即可。

### 第 3 步：安装独立环境

双击 **`setup.cmd`**，或在当前 PowerShell 执行：

```powershell
.\setup.cmd
```

脚本依次创建 `.venv`、安装依赖并准备 Edge 驱动。正常结束时应看到“独立环境准备完成。请先运行‘检查课程.cmd’”。确认没有失败提示后，按任意键关闭安装窗口。

还可以检查依赖是否安装成功：

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe main.py --help
```

第一条应显示 `No broken requirements found.`，第二条显示命令帮助。帮助检查不打开学校网页。后续启动脚本会自动使用 `.venv`，无需手动激活环境。首次安装需要联网；Edge 升级后，可以重新运行安装脚本。

### 第 4 步：核对学校入口、课程和本地标签

用文本编辑器打开 [settings.json](settings.json)，也可以在 PowerShell 中执行：

```powershell
notepad .\settings.json
```

首次使用先核对以下配置，保留文件中其他设置：

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `portal_url` | `https://labsafe.lzjtu.edu.cn/lab-platform/` | 初始登录入口 |
| `home_url` | `https://labsafe.lzjtu.edu.cn/lab-study-front/home` | 学习平台首页 |
| `task_url` | `https://labsafe.lzjtu.edu.cn/lab-study-front/examTask/75` | 目标课程总览 |
| `exam_name` | `2026年实验室安全准入考试（研究生和教职工）` | 进入课程时核对的考试名称 |
| `default_account` | `compatibility-probe` | 本地账号标签，用于隔离浏览器配置与进度 |
| `video_upload_interval_seconds` | `15` | 当前平台视频学时上传周期；补学覆盖完整周期，并留一次轮询时间供上传完成 |

`default_account` 是本地标签，不是学校登录账号。可以改成便于识别的名称；同一标签应始终对应同一个学校账号。更换标签会使用另一套浏览器配置和进度，因此需要重新登录和验证。

当前适配范围是上述学校平台。修改网址和考试名称不代表能够直接适配其他学校的网站。

如果目标考试或年份不同，在网站中打开自己的课程总览，复制地址到 `task_url`，并让 `exam_name` 与网站显示的名称一致。

保存时使用 UTF-8 编码。JSON 使用英文双引号，不支持 `// 注释`，最后一项后面不要加逗号。修改后检查格式：

```powershell
.\.venv\Scripts\python.exe -m json.tool .\settings.json
```

正常输出格式化后的配置表示 JSON 可解析；出现报错时先修正文件再启动。

## 三、首次使用顺序

按 **检查课程 → 验证计时 → 开始学习** 的顺序操作。前一项程序结束后，再启动下一项；同一账号标签只允许一个运行实例。

### 第 5 步：检查课程并手动登录

双击 **`检查课程.cmd`**。程序会打开或复用项目专用 Edge：

1. 在学校初始入口手动登录。
2. 点击“安全教育考试系统 → 进入系统”。
3. 从“个人中心 → 常规考试 → 我的考试”找到目标考试，点击“去学习”。
4. 确认课程名称正确，并能看到必学、选学总时长和课程列表。

程序检测到目标课程页后自动继续，读取两类列表的全部分页并生成 `inventory.json`。检查模式只读取总览和列表，不打开学习材料。

正常结果是终端显示课程读取结果，并在本机 `runtime/` 下生成清单。确认目标课程、总时长和条目正确，等待检查程序结束后，再启动下一步。

若已进入目标课程，但程序仍在等待连接，可以双击 **`登录完成.cmd`**。默认持续等待手动登录，不需要在终端输入密码，也不需要登录 Edge 的 Microsoft 账号。

专用浏览器与日常 Edge 使用不同配置，首次需要重新登录；后续保留学校登录会话。

### 第 6 步：验证文档与视频计时

双击 **`验证计时.cmd`**。程序优先选择剩余时长较短的未达标必学材料，分别进行文档和视频的真实试运行，记录学习前后时长，并等待网站确认。

只有两类材料均得到网站确认，才会报告验证通过。网站记录更新有延迟，此步骤需要等待。若没有可用于验证的未完成文档或视频，程序会暂停提示。

这个步骤会实际打开材料并进行短时学习，不只是检查配置。等待验证程序报告结果并结束；出现暂停提示时，按终端说明处理，再继续验证。

### 第 7 步：开始完整学习

双击 **`开始学习.cmd`**。若真实计时验证尚未通过，程序先完成验证；通过后依次处理未达标必学和选学。

运行时一次只处理一项材料。请保持专用窗口可见，避免在程序学习期间手动切换课程或调整倍速；需要操作页面时，先暂停程序。

### 第 8 步：确认课程学习已经完成

运行期间查看学习终端的状态和提示。最终以网站显示的必学条目、必学总时长、选学总时长为准；程序还需要核对所有待确认记录。只有完整学习结束时才写入 `phase=complete`，计时验证通过并不表示整场学习结束。详细条件见[学习与完成判断](#五学习与完成判断)。

## 四、暂停、继续与停止

| 启动脚本 | 作用 |
| --- | --- |
| `暂停学习.cmd` | 请求暂停，程序在下一次状态检查时暂停视频并保存运行状态 |
| `继续学习.cmd` | 处理页面问题后，通知已暂停的程序继续 |
| `停止学习.cmd` | 停止程序、保存进度，并保留专用浏览器，适用于后台运行 |
| `登录完成.cmd` | 在连接等待阶段，通知程序检查已打开的目标课程页 |

在运行终端按 **Ctrl+C** 也可停止。随后重新运行 `开始学习.cmd`，程序会读取网站最新进度，并核对之前待确认的记录。

登录失效、人工确认、未知材料或持续异常会触发暂停。查看终端提示或 `study.log`，处理浏览器中的问题后，再运行 `继续学习.cmd`。恢复时，已经识别的材料通常先返回总览保存部分进度，再按网站记录重新安排；尚未识别的材料会在原页面重新尝试识别。

`继续学习.cmd` 只通知仍在运行的暂停程序。如果原来的学习终端已经退出，重新运行 `开始学习.cmd` 才能恢复；停止后也通过 `开始学习.cmd` 重启。

暂停程序不会停止网站自身的文档计时器。如果需要立即停止文档学习，可以关闭该学习页，并停止程序。

## 五、学习与完成判断

### 文档

程序读取学习页的“已学习／要求学习”计时器；存在翻页控件时，在要求时长内分配各页展示时间。返回时优先点击网站自身的返回控件，以便网站保存记录。

### 视频

默认使用 **1 倍速**。视频播放进度用于监测播放状态，学习页计时和课程列表记录用于判断学时。

此前使用 2 倍速播放到结尾的课程，可能显示“视频已经学习完”，但累计学习时长仍不足。程序会自动确认明确的“视频已经学习完，是否重新学习！”提示，正常重播；播放再次结束而计时仍不足时，继续重播。其他确认提示需要人工处理。

存在网页计时器时，只有达到本次需要的学习时长才会正常切换。前一课的记录到达核对时间，也不会提前退出当前视频；核对会延后至当前视频完成。网页计时连续 120 秒不增加时暂停并保留当前页面。

没有可识别网页计时器的视频，使用实际观察到的播放时间安排一次网站记录核对，本地播放时间本身不授予完成状态。

### 题库练习

题库是独立学习模块，默认每次浏览 900 秒。程序从网站“可练习题库”选择题库，读取“练习时间”，滚动浏览当前题页，达到本次时长后提交 **1 道**参考题，再点击网站自身“退出”控件，保存记录并安排下一题库。剩余要求不足 15 分钟时按剩余时长处理。

答案参考来自[山东第二医科大学医学研究实验中心公开题库（2024 年 3 月）](https://syzx.sdsmu.edu.cn/_upload/article/files/68/5c/caefec194d1fbf6efcbd138663d4/b36430f2-2323-4d3c-80cb-2b67d0eed9b6.pdf)。只有题干和所有选项均匹配、参考答案不冲突时才提交；选项按内容对应，保留负号、小数点、比较符号和单位。已答题目不重复提交。参考索引保存哈希和出处页码，不保存参考题库全文。

每个题库最多查看前三页寻找匹配题目，没有匹配则检查下一题库；八个题库都找不到时暂停。网站显示的正确答案与提交答案不一致时暂停。练习答案确认后不能修改；使用前应了解这一自动提交行为。

真实短时试运行发现：只浏览 61 秒并退出，五分钟后总览仍未增加；另一次正常浏览并提交一道题，网站判定正确后累计时长从 00:00:29 增至 00:01:31。页面计时本身不能证明学时已保存，仍以网站确认记录为准。

题库同样支持暂停、继续、停止以及重启恢复。每次退出保存后轮换下一题库；尚未网站确认的记录不重复学习。首轮电气安全题库已完成 15 分钟自动提交、正确反馈与退出保存；八库连续轮换仍需真实运行验证。

### 网站记录确认

完成一次学习后，程序保存“待网站确认”状态，至少等待 5 分钟再接受课程列表中的更新。等待期间可以继续下一课；文档可能先保存部分进度以核对旧记录，视频保持连续播放。

没有下一项可学材料时，程序停留在总览等待，不反复切换“已学／未学”和分页；首次核对安排在保存后至少 5 分钟，记录仍未更新时每分钟最多再核对一次。暂停、停止信号在等待期间同样有效。核对更新后按题库轮换位置继续；切换时等待题目和计时器均加载就绪。

网站只记录部分新增时长时，程序按剩余时长安排补学。核对时发现提交后超过 10 分钟仍无时长增加，则暂停报告；正在播放的视频会使实际核对时间顺延。待确认材料不会立即重复学习。

完整学习结束需同时满足：

- 所有必学条目达标。
- 必学总时长达标。
- 选学总时长达标。
- 没有待网站确认的记录。

选学只需达到总时长要求，最后一项选学可能只学习所需的剩余时长。结束时 `status.json` 中的 `phase` 为 `complete`；`validation_complete` 仅表示计时验证结束。

## 六、命令行使用

以下命令与对应的中文启动脚本等价：

```powershell
# 只检查课程总览和列表
.\.venv\Scripts\python.exe main.py --inspect

# 只执行真实文档、视频计时验证
.\.venv\Scripts\python.exe main.py --validate-only

# 验证通过后继续完整学习
.\.venv\Scripts\python.exe main.py --run
```

为另一学校账号指定独立的本地标签：

```powershell
.\.venv\Scripts\python.exe main.py --run --account teacher1

# 控制命令必须使用相同标签
.\.venv\Scripts\python.exe control.py pause --account teacher1
.\.venv\Scripts\python.exe control.py resume --account teacher1
.\.venv\Scripts\python.exe control.py stop --account teacher1
```

中文控制脚本使用 `settings.json` 中的默认标签。如果通过命令行指定其他标签，请使用带同一 `--account` 的控制命令。

## 七、其他配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `browser_backend` | `native` | 专用 Edge 连接方式；可选 `webdriver` |
| `restart_finished_video` | `true` | 是否自动确认明确的已结束视频重播提示 |
| `keep_browser_open` | `true` | 程序退出后保留专用浏览器 |
| `poll_seconds` | `3` | 页面状态检查间隔，单位为秒 |
| `questionbank_session_seconds` | `900` | 题库每次浏览时间，默认每 15 分钟提交 1 道核验题并退出轮换 |
| `confirmation_delay_seconds` | `300` | 接受学习记录更新前的最短等待时间 |
| `confirmation_timeout_seconds` | `600` | 无记录增加时的确认超时阈值 |
| `stall_seconds` | `120` | 播放或计时持续停滞的暂停阈值 |
| `login_timeout_seconds` | `0` | `0` 表示持续等待手动登录 |
| `driver_path` | `drivers/msedgedriver.exe` | 可选 WebDriver 驱动路径 |

时间配置的单位为秒；检查间隔必须大于零，确认超时必须大于确认等待时间。调整配置后需重启程序才会生效。

## 九、常见问题

**双击安装或启动脚本后窗口报错，应该先检查什么？**

先在项目目录打开 PowerShell，执行 `python --version`，确认 Python 可用；再运行 `.\setup.cmd`。确认 `.venv\Scripts\python.exe` 已生成，且安装没有报错，然后执行本教程中的依赖检查和入口帮助。这样可以保留错误文字，避免只看到窗口闪退。

**`ModuleNotFoundError`、找不到 `.venv\Scripts\python.exe`。**

重新运行 `setup.cmd` 安装环境。命令行启动时也使用项目中的 `.venv` Python，避免安装和运行使用了不同环境。

**修改配置后出现 `JSONDecodeError`。**

检查是否使用英文双引号、是否包含注释或多余逗号，执行 `.\.venv\Scripts\python.exe -m json.tool .\settings.json` 定位错误。

**专用窗口空白、提示“格式显示错误”或“服务器异常，未知原因”。**

先确认学校入口在日常浏览器中能打开。程序已暂停时，从专用窗口的学校初始入口重新登录并进入目标课程，再运行 `继续学习.cmd`；等待连接时使用 `登录完成.cmd`。这些提示不能单独确定根因，重复出现时查看诊断文件。

**视频已经播放结束，为什么还在重播？**

播放到结尾与学习学时达标是两个不同状态，尤其是此前使用倍速播放的课程。程序按网页计时补足时长，再等待网站确认。

**刚学完，总览为什么没有立即变化？**

网站提示学习记录约 5 分钟后更新。查看 `state.json` 的待确认记录和运行日志，等待核对；不要立即启动第二个程序重复学习。

**重复启动提示已有运行实例。**

同一账号标签只允许一个实例。检查已有终端或日志；如需重启，先运行 `停止学习.cmd`，等待原程序退出。

**安装时驱动下载失败。**

检查下载网络后重新运行 `setup.cmd`。需要手动准备时，在 Edge 中打开 `edge://settings/help` 查看版本，从[微软官方驱动页面](https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/)下载对应架构的驱动，并将解压后的 `msedgedriver.exe` 放入项目的 `drivers/` 目录。驱动与浏览器四段版本号的前三段应一致，见[微软说明](https://learn.microsoft.com/en-us/microsoft-edge/webdriver/#download-microsoft-edge-webdriver)。

手动放入驱动不会让安装脚本跳过 Selenium Manager 的联网检查。默认 `native` 后端通过本机调试接口连接 Edge；驱动供 `webdriver` 后端和部分本地浏览器测试使用。若依赖已成功安装但驱动准备失败，可先执行 `pip check` 和 `main.py --help` 的检查，再尝试默认后端的 `检查课程.cmd`；浏览器测试及可选后端仍需单独准备驱动。学校网页是否可访问也要另外检查。

**程序提示无法识别材料或存在多个计时器。**

当前适配会在多课时无法唯一识别、列表与学习页要求不一致或未知材料等情况下暂停。保留诊断信息，根据真实页面继续适配；分享截图和日志前检查其中的账号信息。

## 十、测试与验证范围

截至 **2026-10-11** 的验证记录：此前题库等待与切换修复版本通过 **87 项测试**，包含真实 Edge 加载本地模拟页面的测试。随后的视频学时上传修复版本执行 **94 项测试，其中 60 项通过、34 项需要显式启用的浏览器测试跳过**；不能把后者描述为全部浏览器测试已重新通过。

真实学校课程已完成至少一项文档和一项自动视频的计时、返回保存与延迟记录确认；题库首轮 15 分钟正常提交已由网站判定正确并增加累计学时。视频短时补学修复也记录了两项材料的真实网站确认。详细记录、日期和验证条件见 [VERIFICATION.md](VERIFICATION.md)。

这些结果不表示所有课程页面均已适配，也不表示整场课程已完成。其他真实跨域 iframe、整场选学停止等仍有未验证范围，详见 [验证报告](VERIFICATION.md)。

执行默认测试（浏览器测试默认跳过）：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

显式启用本地 Edge 浏览器测试：

```powershell
$env:LABSAFE_BROWSER_TESTS = '1'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
Remove-Item Env:LABSAFE_BROWSER_TESTS
```

浏览器测试使用本地模拟页面，不登录学校账号；需要安装 Edge 并准备匹配的驱动。
